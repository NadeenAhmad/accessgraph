# Scripts

Standalone utility scripts for AccessGraph.

| Directory | Purpose |
| --- | --- |
| `scripts/development/` | Local fixture serving for crawler and benchmark smoke tests. |
| `scripts/evaluation/` | Seeded case scoring and generic model-judgment comparison utilities. |
| `scripts/benchmarks/` | Controlled benchmark acquisition and validation scripts. |

Human-review and historical reproduction scripts remain in the thesis repository.
